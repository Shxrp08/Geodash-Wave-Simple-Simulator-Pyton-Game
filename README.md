**⚠️ My Error Experiences :)**

**1. Incorrect Terminal Path (`No such file or directory`)**
If the terminal cannot find the script, it is likely running in the wrong default directory (such as the VS Code default folder). You must change the directory to the exact folder where the game is located using the `cd` command before executing the file.

**Example:**
`cd C:\Users\YourName\Documents\YourGameFolder`
`python geodash_wave_game.py`

**2. Python Version & Pygame Issues**

`# If the terminal states that Pygame is missing, or if the game crashes due to `
`# an incompatible or newer Python release, you can force the terminal to execute `
`# the script using a specific, stable Python version (such as Python 3.12) `
`# where Pygame is already installed.`

py -3.12 geodash_wave_game.py
